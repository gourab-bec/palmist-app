# Moved

The Suresh Vuyyuru campaign site does not live here. It is at
**[gourab-bec/suresh-2026](https://github.com/gourab-bec/suresh-2026)**.

This directory briefly held a parallel Phase 0 — research notes, a tooling matrix, a fact
pack, and a domain runbook — written before the real build was located. That build already
existed and was better: it had certified 2024 vote totals this version did not, and it
correctly withheld a blood-drive claim that this version would have published, because the
Tracy Press coverage names no individual volunteers.

The runbook here was also wrong twice over by August 23: it recommended `sureshformountainhouse.com`
when the campaign bought `suresh4mountainhouse.com`, and Namecheap when the registrar is
Network Solutions. Two contradictory sets of launch instructions is worse than one, so this
one is gone rather than left to be found later by someone in a hurry.

The content is recoverable from git history if it is ever wanted. Everything current —
including `LAUNCH.md` and `docs/DNS-AND-DEPLOY.md` — is in the other repository.

This repository is the Palmly palmistry app and is otherwise unrelated.
